# Raw-вимірювання лабораторної №2

JSON-файли цього каталогу генеруються локально командою:

```powershell
python -B scripts/run_lab2.py
```

Профілі N=1…4 додано до репозиторію у вигляді `n1_profile.json.gz`…`n4_profile.json.gz`. Після розпакування це ті самі JSON, для яких нижче наведено SHA-256. Стиснення виконується командою:

```powershell
python -B scripts/package_lab2_raw.py
```

`noop_profile.json` має розмір понад 400 MiB, тому він залишається локальним; для нього в репозиторії збережено SHA-256, посекундний файл і компактний підсумок. Аналізатор та незалежний verifier у чистому checkout автоматично читають `.json.gz`, якщо нестисненого JSON немає.
