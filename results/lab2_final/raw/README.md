# Raw-вимірювання лабораторної №2

JSON-файли цього каталогу генеруються локально командою:

```powershell
python -B scripts/run_lab2.py
```

Вони не додаються до Git, оскільки `noop_profile.json` має розмір понад 400 MiB і перевищує ліміт одного файла GitHub. Файли не видалені з локального робочого каталогу. Компактні похідні результати, Prometheus-зрізи, ресурсні вимірювання, графіки та незалежна перевірка зберігаються в `results/lab2_final`.
