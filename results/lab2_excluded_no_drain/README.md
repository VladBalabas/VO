# Виключений попередній прогін

Цей каталог локально містить попередній прогін, у якому наступне N запускалося до завершення серверної черги попереднього профілю. Його не використано у фінальних таблицях, графіках або USL-fit.

Великі raw-файли прогону не додаються до Git. Каталог збережено локально лише як аудиторський слід виявленої методичної помилки.
